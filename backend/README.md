# Local Bites — Backend API

Step 2 of the Local Bites project: a FastAPI backend with a database
that stores deals and businesses, and serves them over HTTP so the
mobile app (built later) can fetch them.

## Files

- `database.py` — database connection (SQLite by default).
- `models.py` — the actual database tables (Business, Deal).
- `schemas.py` — what the API accepts/returns (separate from the DB
  tables on purpose).
- `main.py` — the FastAPI app and its endpoints.
- `seed_from_parsed_deals.py` — loads the `parsed_deals.json` file
  produced by the deal-parser project into this database.

## Setup

```bash
pip3 install -r requirements.txt
```

## Load your parsed deals into the database

Copy the `parsed_deals.json` file you generated in the deal-parser
project into this folder, then run:

```bash
python3 seed_from_parsed_deals.py
```

This creates a `local_bites.db` file (a SQLite database — just a
single file, nothing to install or configure) and loads all your
parsed deals into it, auto-creating a business record for each one.

## Run the API

```bash
uvicorn main:app --reload
```

Leave this running in Terminal — it starts a local web server. Open
your browser to:

**http://127.0.0.1:8000/docs**

This is an interactive API playground (auto-generated by FastAPI). You
can click into any endpoint, hit "Try it out," and see real results
from your database — no separate tool needed.

Things to try:
- `GET /deals` — every deal in the database
- `GET /deals?category=drinks` — filter by category
- `GET /deals?day=tuesday` — filter by day of week
- `GET /deals?min_confidence=0.9` — hide lower-confidence parses
- `GET /businesses` — every business

## Moving to Postgres later (optional, not needed now)

When you're ready to deploy for real (or want semantic search with
pgvector), set an environment variable before running anything:

```bash
export DATABASE_URL=postgresql://user:password@host:5432/dbname
```

Nothing else in the code needs to change — `database.py` reads this
automatically and falls back to SQLite if it's not set.
